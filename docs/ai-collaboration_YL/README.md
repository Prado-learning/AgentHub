# AgentHub AI 协作开发记录

这份目录用来沉淀 AgentHub 项目的 AI 协作规范、历史演进和可复用能力卡。飞书文档负责对外说明和流程入口，仓库负责保存可版本化的规范正文与产物地址。

## 现在的结论

AgentHub 已经从单聊天和前端演示，演进成一个配置驱动的多 Agent 协作工作台。当前协作重点不是“让 AI 直接改代码”，而是把 AI 的角色、边界、输出格式和验证方式固定下来，减少重复沟通和不可控修改。

## 历史演进摘要

- 2026-06-06: 单聊、群聊和前端重构，先把协作入口和基础 UI 搭起来。
- 2026-06-07: 框架重构，自建 Agent 体系，开始引入可配置的 adapters、tools、skills。
- 2026-06-09: 多模态、附件、Diff、记忆、多对话框和 workflow 能力补齐，系统开始支持产物化协作。
- 2026-06-09: 仓库开放前整理，说明项目已经接近可对外沉淀的状态。
